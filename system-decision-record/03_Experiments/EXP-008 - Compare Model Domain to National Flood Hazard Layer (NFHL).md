## Description

Check whether a domain-generation approach would yield an acceptable size given the NFHL as a reference FIM.

## Methodology
1. Select a method for domain generation and/or expansion.
2. Generate a model domain for a reach.
3. Measure NFHL width in the reach vicinity.
4. Compare extents of model domain to NFHL 100-year floodplain (Zone A/AE)
